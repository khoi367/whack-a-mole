# Whack-a-Mole

Một trò chơi "đập chuột" đơn giản bằng HTML, CSS và JavaScript.

## Chạy local

- Mở file `index.html` trong trình duyệt.
- Hoặc dùng các dịch vụ local web server nếu muốn.

## GitHub Pages

Sau khi bật GitHub Pages trong Settings > Pages, chọn branch `main` và thư mục `/ (root)`, trang sẽ hiển thị tại:

https://khoi367.github.io/whack-a-mole/

## Cách chơi

- Nhấn nút **Bắt đầu**.
- Khi con chuột xuất hiện, click vào nó để ghi điểm.
- Trò chơi kết thúc khi hết thời gian.
